---
title: Página não encontrada
description: O que fazer quando um endereço dos tutoriais públicos do Épico Site não corresponde a uma página publicada.
---

O endereço acessado não corresponde a nenhuma página dos tutoriais do Épico Site. As causas mais comuns são um erro de digitação no link ou uma página antiga que foi substituída por outra.

Caminhos para seguir:

- [Voltar para o início](/), com a visão geral das seis áreas.
- [Buscar por palavra-chave](/busca/), cobrindo todos os tutoriais publicados.
- Abrir a área desejada pela barra lateral.

Se você chegou aqui por um link externo, a [busca](/busca/) ajuda a encontrar o tutorial correspondente pelo tema.
